# 知识单元拆分规范V2\.0

## 一、规范目的

知识单元的拆分不能按教材标题、编号或段落机械切分，而应以知识是否能够**独立理解、独立命题、独立复习**作为主要判断依据。

教材中的篇、章、节、目、条、标题和编号只作为拆解参考。真正决定知识单元边界的，是命题点、核心结论、适用条件以及知识之间的逻辑关系。

## 二、知识单元的基本标准

一个合格的知识单元，至少应包含：

```text
知识对象 + 核心结论 + 适用条件 + 必要边界/例外 + 来源
```

例如：

```text
知识对象：模板拆除条件
核心结论：达到规定条件后方可拆模
适用条件：构件类型、跨度、混凝土强度
边界/例外：特殊部位不能直接套用普通条件
来源：教材章节、规范条文
```

知识单元本身应当可以被单独阅读、讲解、复习和命题。

## 三、应该拆分的情况

满足以下任意一项，通常可以拆成不同知识单元：

|判断条件|示例|
|---|---|
|回答的问题不同|“何时拆模”与“按什么顺序拆模”|
|核心结论不同|“索赔成立条件”与“索赔程序”|
|适用条件不同|普通施工条件与冬期施工条件|
|命题方式不同|一个考概念，一个考计算|
|复习依赖不同|学习 A 不影响理解 B|
|容易单独出题|历年题目经常单独考查|
|来源依据不同|分别对应不同规范条款|
|责任主体或动作不同|建设单位责任与施工单位责任|

拆分时，应确保拆分后的每个单元仍然具备完整的问题、结论和必要条件，不能只截取一个孤立数字、动作或句子。

## 四、应该合并的情况

以下内容不要继续拆碎，应放在同一个知识单元的“内容要素”中：

|情况|处理方式|
|---|---|
|同一个问题下的多个条件|合并到“适用条件”|
|同一结论的补充说明|放入“补充说明”|
|例子、案例、解释|作为“示例”或“应用场景”|
|公式中的多个参数|放入“计算要素”|
|同一规则下的数字要求|放入“定量要求”|
|一般规则的特殊限制|放入“例外情况”|
|同一流程中的连续动作|保留为一个“步骤关系”|

如果拆出后的内容不能独立回答一个专业问题，或者必须依赖相邻内容才能理解，应优先合并。

## 五、推荐的四层结构

不要把所有内容都做成同一级知识单元，建议采用以下四层结构：

```text
章节 / 目录
  └── 命题点
        └── 知识单元
              └── 内容要素
```

例如：

```text
主体结构施工
  └── 模板工程
        ├── 模板拆除条件
        │     ├── 强度要求
        │     ├── 构件类型
        │     └── 特殊部位限制
        └── 模板拆除顺序
              ├── 非承重部分
              └── 承重部分
```

这里，“模板拆除条件”和“模板拆除顺序”是两个知识单元；“强度要求”和“构件类型”是内容要素，不必再拆成独立单元。

## 六、五问判断法

对每个候选知识单元连续问以下五个问题：

1. 只看这个单元，能否说清楚一个完整结论？

2. 能否围绕它设计一道独立题目？

3. 它是否有明确的适用条件？

4. 拆掉其中一部分后，剩余内容是否仍然成立？

5. 它是否需要和另一个单元一起才能理解？

判断规则：

- 前 3 个问题大多回答“是”，可以作为独立知识单元。

- 第 4 个问题回答“否”，说明拆得太细，应合并。

- 第 5 个问题回答“是”，说明两部分可能属于同一知识单元。

## 七、颗粒度控制规则

以下规则可作为系统校验规则，但不能作为绝对限制：

- 一个知识单元只保留一个主问题。

- 一个命题点通常拆成 1～3 个核心知识单元。

- 一个知识单元一般包含 1 个核心结论、若干条件和少量例外。

- 单独只有一个数字、一个动作或一句补充说明时，通常不应单独成单元。

- 标题中出现“和”“以及”“同时”时，应重点检查是否包含多个独立问题。

- 单元过长时，优先拆成“主知识单元 \+ 内容要素”，不要简单按句子切开。

- 单元过短时，优先与相邻内容合并，前提是它们回答同一个问题。

## 八、常见错误

### 1\. 拆得过粗

```text
混凝土工程施工
```

其中同时包含配合比、浇筑、振捣、养护、拆模等多个命题主题，无法精准复习和出题，应根据不同问题拆分为多个知识单元。

### 2\. 拆得过细

```text
混凝土浇筑后要覆盖塑料膜
混凝土终凝后要覆盖土工布
混凝土表面要洒水
```

这三条共同回答的是“混凝土如何养护”，更适合作为一个“混凝土养护”知识单元下的三个内容要素。

## 九、知识单元的标准展示结构

每个知识单元建议使用以下结构进行说明：

```text
知识单元标题

回答的是：

> 一个完整、明确的专业问题？

主要内容是：

- 内容要点一
- 内容要点二
- 内容要点三

这是“某类知识”的知识。
```

其中：

- “回答的是”用于明确该单元的主问题。

- “主要内容是”用于列出回答该问题所必需的核心要素。

- “这是……的知识”用于标明该单元所属的知识类型或命题角度。

## 十、最终边界定义

知识单元的边界定义为：

> **能独立回答一个专业问题，并保留回答该问题所必需的条件、例外和依据。**
> 
> 

教材中的层级、编号和段落只作为拆解参考；真正决定是否拆分的，应是命题点、核心结论和知识之间的逻辑关系。

## 十一、拆分结果验收清单

每个知识单元完成后，至少检查以下内容：

* [ ] 是否只有一个主问题？

* [ ] 是否能够独立理解？

* [ ] 是否能够设计独立题目？

* [ ] 是否保留了必要的适用条件？

* [ ] 是否保留了必要的边界和例外？

* [ ] 是否保留了教材或规范来源？

* [ ] 是否把数字、例子和补充说明错误拆成了单独单元？

* [ ] 是否与相邻单元存在重复或边界不清？

* [ ] 是否能明确归入某个命题点？

* [ ] 是否符合“章节 / 命题点 / 知识单元 / 内容要素”四层结构？
