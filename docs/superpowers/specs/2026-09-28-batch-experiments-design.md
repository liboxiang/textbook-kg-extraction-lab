# 批量知识点实验设计

## 目标

允许一次导入多个知识点，按一个批次管理其阶段状态和结果；每个知识点仍独立执行 Stage 1、人工确认、Stage 2 和最终图谱，避免未经确认的跨 KP 关系。

## 数据与任务

在现有实验记录上增加 `batch_id` 和 `batch_name`，批次元数据记录总数、完成数、失败数和汇总状态。每个 KP 仍是一条批次子记录，保留自己的输入、阶段结果、最终 JSON 和任务目录。创建批次时为每个 KP 生成独立 Stage 1 任务，Codex 继续按仓库“处理最新任务”规则逐个完成。

## 页面

新增“批量实验”功能入口，支持粘贴 JSON 数组或上传 JSON 文件。导入后显示批次表格：KP、当前状态、状态描述、阶段进度和操作。每个已完成 KP 提供“查看结果”和“查看图谱”按钮；批次总览显示总数、已完成、失败和进行中数量。

## 边界

- 不修改现有单 KP 流程。
- 不自动推断不同 KP 之间的知识关系。
- 不生成跨 KP 合并图谱；批次页只做汇总，图谱仍按 KP 查看。
- 旧单 KP 记录自动视为单项批次兼容展示。

## 验收

1. 可导入并校验至少两个 KP。
2. 每个 KP 生成独立 Stage 1 任务并绑定同一批次。
3. 批次页能显示子任务状态和统计。
4. 已完成子任务可以直接打开最终图谱。
5. 旧记录和单 KP 实验继续可用。
