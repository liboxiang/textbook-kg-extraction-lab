# 按教材论述模块划分 KU：设计说明

## 目标

Stage 1 将 KP 原文无损划分为若干可整体阅读、检索、讲解和输出的 KU。KU 保留教材作者围绕一个主题展开的完整结果；条目、条件、参数、步骤和例外由 Stage 2 作为内容要素抽取。

## 边界语义

教材标题及编号是作者论述层次的证据，但不自动产生边界。只有相邻内容转向不同论述主题、两侧都能独立形成完整结果，且后一部分不是前一部分的组成、条件、参数、步骤、例外、示例或补充时，才建立新 KU。可以单独命题不构成充分拆分理由。`main_question` 是统领整个模块的问题，允许内部子问题。

## 数据流与兼容性

保持 Stage 1 和 Stage 2 现有 JSON Schema 不变。新建 `ku_split/v1.1.md` 与 `ku_extract/v1.1.md`；旧版保留，方便历史实验复现。更新仓库操作指令与抽取 Skill，使模式 A 遵循新规范。当前任务保留原输入和 Source Block，只修订任务说明和 Stage 1 结果。

## 验证

当前教材样本按作者的五个完整论述模块重划。运行 `validate_codex_result.py` 确认全部 266 个 Source Block 连续覆盖，并检查原文的编号条目仍位于各自上位模块之内。
