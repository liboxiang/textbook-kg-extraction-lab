# 历史评测图谱切换与界面精简设计

## 目标

修复历史评测下载的 HTML 总览中切换知识点后图谱显示不正确的问题，并删除图谱下方与节点详情重复的完整内容区。

## 设计

- 历史评测 HTML 总览继续使用单个知识点选择器和内嵌 `REPORTS` 数据。
- 选择知识点时，统一更新当前报告、元信息、SVG 图谱和右侧节点详情初始状态，确保不残留上一个知识点的图谱或详情。
- 保留点击节点查看属性、教材原文、内容和拆分证据的能力。
- 删除图谱下方 `result` 面板及其完整 KU、证据、内容要素表渲染逻辑，避免重复展示。
- 单条“查看图谱”弹窗不改变布局，仍保留图谱和右侧节点详情。

## 验证

- 运行 Python 编译检查。
- 生成历史 HTML 后检查不再包含 `id='result'` 和 `renderResult`。
- 启动 Streamlit 并确认页面可访问。
