# Stage 1 Prompt V1.3 设计

## 目标

生成通用于不同教材主题的 Stage 1 提示词，避免将当前道路教材中的知识对象写入规则正文并诱导模型套用案例。

## 版本策略

- 保留 V1.1 和 V1.2，确保历史运行可追溯。
- 新建 V1.3，并设为 Stage 1 默认版本。
- V1.3 以 V1.1 的结构为基础，不包含 V1.2 的“总起句与并列分项的完整性规则”。

## 通用化规则

“特别防止过细拆分”只描述知识结构关系：上位知识对象、统领性问题、内容角色、语义依赖和专业任务转换。不出现垫层、基层、面层、纵缝、横缝、传力杆、抗滑构造等当前样本对象。

## 原文证据链

Stage 1 继续仅输出 KU 的 Source Block 起止边界。程序通过边界精确重建 `source_text`，Stage 2 接收每个 KU 的完整 `source_text` 和 `source_blocks`，内容要素使用 `evidence_block_ids` 回指证据。模型不重复抄写原文，以避免遗漏或改写。
